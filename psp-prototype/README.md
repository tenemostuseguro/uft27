# UFT FUT15 Visual Card Lab — PSP / PPSSPP

Prototype focused exclusively on FIFA 15-style Ultimate Team card and pack experiments. There are no matches in this build.

## Included

- Six-player test packs.
- LAB pack with boosted special-card odds for testing.
- Normal pack with much lower special-card odds.
- Reveal cards one by one or reveal all.
- Open a full card detail view.
- Browse the compiled FIFA 15 historical database.
- Shows player name, club, league, position, version, rating and PAC/SHO/PAS/DRI/DEF/PHY.
- Uses the visual card assets supplied for the PSP prototype.

## Data build

GitHub Actions downloads the historical FIFA15.csv from `kafagy/fifa-FUT-Data` and the FIFA 15 special-card catalogue from `MateuszMachowina/PackOpenerF15`. The generator cross-references rating, position and six face stats to assign known special versions, then compiles the resulting dataset into the EBOOT.

The downloaded artifact also contains `FUT15_DATABASE_INFO.txt` with the exact number of cards, clubs, leagues, positions and matched special-version rows generated by that build.

## Visual assets

`psp-prototype/card_assets_psp.zip` contains the PSP-optimised mini and full card templates. The workflow extracts them next to the EBOOT in the final artifact.

## Controls

### Menu
- D-Pad Up/Down: move
- X: select
- START: exit

### Pack
- Left/Right: select card
- X: reveal selected card; press X again to open its detail
- Triangle: reveal all six cards
- Circle: return to menu

### Database
- Left/Right: previous/next card
- Up/Down: jump 50 cards
- Triangle: random card
- Circle: return to menu

## Install

Keep the generated `UFT15` folder intact, with `EBOOT.PBP` and its `assets/` folder together, then load `EBOOT.PBP` in PPSSPP.
